# Project Statement

## Problem Statement

Managing library books and student records manually can be time-consuming and may lead to errors in tracking issued books, due dates, and fines. The Library Fine Calculator provides a simple system to manage these activities efficiently.

## Scope of the Project

The project covers student registration, book management, book issue and return, automatic due-date calculation, fine calculation, searching records, and saving/loading library data using file handling.

## Target Users

- College library staff
- Students
- Small library administrators

## High-Level Features

- Add student members
- Add books
- Issue books to students
- Automatically set a 14-day due date
- Return books
- Calculate late fines at ₹5 per day
- Search books and members
- View library records
- Save and load library data
