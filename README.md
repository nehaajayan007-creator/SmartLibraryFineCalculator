# Library Fine Calculator

A Java console application to manage library books and student members and calculate library fines.

## Overview

Library Fine Calculator allows users to add books, register students, issue and return books, calculate late fines, and search library records.

The project is developed using core Java and Object-Oriented Programming concepts.

## Features

- Add student members
- Add books
- Issue books to students
- Automatically calculate a 14-day due date
- Return books
- Calculate fine at ₹5 per day for late returns
- Search books
- Search student members
- View all books and members
- Save library data to a file
- Load saved data when the application starts
- Handle invalid input and exceptions

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Exception Handling
- File I/O
- Java Date and Time API
- Visual Studio Code
- Git
- GitHub

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio Code.
3. Open `src/library/Main.java`.
4. Run `Main.java`.
5. Follow the instructions shown in the terminal.

## Testing

The following functions can be tested manually:

- Add a student
- Add a book
- Issue a book
- Check the automatic 14-day due date
- Return a book
- Check fine calculation
- Search for a book
- Search for a student
- Try adding duplicate IDs or ISBNs
- Restart the application and check whether saved data is loaded
- Enter invalid or empty input
